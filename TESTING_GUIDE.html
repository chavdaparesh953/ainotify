1. Core Infrastructure & 4-Terminal Startup Prerequisites

ℹ️

Runs backend on port 4000 for webhook ingestion and REST APIs.

Terminal 3

7. Security, Signature Verification & Edge Cases Security Auditing

Ensuring unauthorized or forged webhooks are rejected with HTTP 401.

Security Test 1: Forged / Tampered HMAC Signature
Send a webhook with an altered payload or invalid signature. Must return HTTP 401 Unauthorized:
cURL Tamper Test 
curl -X POST http://localhost:4000/api/webhooks/receive \
  -H "Content-Type: application/json" \
  -H "X-Shopify-Shop-Domain: test-brand.myshopify.com" \
  -H "X-Shopify-Topic: orders/create" \
  -H "X-Shopify-Hmac-Sha256: FAKE_TAMPERED_BASE64_SIGNATURE==" \
  -d '{"id":99999,"total_price":"999.00"}'
Security Test 2: Unregistered Store Webhook Rejection
Webhooks from domains not registered in PostgreSQL must be rejected with HTTP 404 Not Found.
Security Test 3: Malformed Phone Number Protection
When an order contains a landline or 4-digit number, verify that the worker logs FAILED with reason INVALID_OR_MISSING_PHONE without crashing the BullMQ worker process.

9. Troubleshooting & Common Error Codes Reference Error Matrix

Quick reference for common Meta, Shopify, and Redis error codes.

Error Code / Symptom Root Cause Fix / Solution
Meta Error 190 OAuth Token expired or invalid Temporary token expires after 24h. Generate a new one in Meta Developer Console or create a permanent System User Token.
Meta Error 131026 User not registered on WhatsApp Expected for non-WhatsApp numbers. Enable Fallback to SMS in store settings to trigger SMS dispatch.
Meta Error 131047 24-hour customer window expired Business must initiate conversation using a pre-approved Meta Template (type: template), not freeform text.
Meta Error 100 Invalid parameter / Template mismatch Verify template name matches exactly in Meta Message Templates Manager (case-sensitive) and language code is set to en_US.
HTTP 401 Invalid Signature Webhook secret mismatch Ensure the secret entered in Shopify/Woo matches webhookSecret in the database stores table.
ECONNREFUSED 127.0.0.1:6379 Redis server is offline Start Redis service: brew services start redis or run redis-server in a terminal.
Ngrok ERR_NGROK_3200 Ngrok tunnel closed or expired Run npm run dev:tunnel again and update the webhook URL in Meta / Shopify.
